# AECoBuild installers

Download installers for [AECoBuild](https://aecobuild.com), the free, offline 3D architectural modeler by CloudBrain (Delhi NCR, India). This repository only hosts the installers; it holds no source code.

**[Download the latest release](https://github.com/clbrain/aecobuild-release/releases/latest)**

| Platform | File | Requirements |
|---|---|---|
| macOS | `AECoBuild-macOS-AppleSilicon.dmg` | macOS 11 or later, Apple Silicon (M1–M4). On an Intel Mac, use the [web modeler](https://aecobuild.com/web). |
| Windows | `AECoBuild-Windows-x64.msi` or `AECoBuild-Windows-x64-setup.exe` | Windows 10 (1809) or 11, 64-bit |

The file names stay the same in every release, so these links always fetch the newest version:

- macOS: https://github.com/clbrain/aecobuild-release/releases/latest/download/AECoBuild-macOS-AppleSilicon.dmg
- Windows (.msi): https://github.com/clbrain/aecobuild-release/releases/latest/download/AECoBuild-Windows-x64.msi
- Windows (.exe): https://github.com/clbrain/aecobuild-release/releases/latest/download/AECoBuild-Windows-x64-setup.exe

Each release lists the SHA-256 checksum of every file.

## Opening the app the first time

The installers are not code-signed yet, so your system asks you to confirm once.

**macOS 15 Sequoia and later:** open AECoBuild and click **Done** when macOS says it cannot verify the app. Then open **System Settings → Privacy & Security**, scroll to Security and click **Open Anyway** next to AECoBuild.

**macOS 14 Sonoma and earlier:** in Applications, right-click (or Control-click) AECoBuild, choose **Open**, then **Open** again.

**Windows:** if SmartScreen shows "Windows protected your PC", click **More info**, then **Run anyway**.
